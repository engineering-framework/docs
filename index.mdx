## What is Engineering Framework?

Engineering Framework is a full-stack framework for multi-tenant organization
management. It provides:

- A **web application** for managing organizations, departments, and users
- A **Framework MCP server** that exposes the same operations as Model Context
  Protocol tools, so AI agents can manage organizations, users, and permissions
- A **Knowledge Base** for ingesting and querying project documentation
- Shared **authentication** and **fine-grained authorization** layers used
  consistently across the web app and MCP server
